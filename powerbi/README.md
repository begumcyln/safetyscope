# Power BI assets

Full instructions, test status and layout: [`docs/POWER_BI_GUIDE.md`](../docs/POWER_BI_GUIDE.md).
Status: the project was **opened, refreshed and validated in Power BI Desktop on Windows** (KPIs match the
Python/SQL results); the theme has not been applied yet.

| Path | Content |
|---|---|
| `SafetyScope.pbix` | Report saved from Power BI Desktop (4 pages) — open directly on Windows |
| `pbip/` | Power BI Project source (TMDL model + PBIR report), Git-friendly text format |
| `data/` | The 5 star-schema tables as CSV (UTF-8) that the model loads |
| `SafetyScope_PowerBI_upload.xlsx` | Same 5 tables as Excel Tables, for building the report in app.powerbi.com (browser route; not tested) |
| `power_query/` | M scripts per table + `DataFolder` parameter + Calendar |
| `dax/measures.dax` | 17 DAX measures with descriptions and format strings |
| `theme/SafetyScope_theme.json` | Report theme (colour-vision-deficiency-checked palette) |
| `tools/schemas/` | Microsoft JSON schemas used to validate the PBIR files (MIT licence, see `LICENSE_microsoft_json-schemas.txt`) |

**Data path.** The model reads the CSVs from the `DataFolder` parameter (default `C:\SafetyScope\powerbi\data\`).
On another location: *Home → Transform data → Edit parameters → DataFolder* (path must end with `\`), then *Refresh*.

Generated by `python src/build_powerbi.py` (except `SafetyScope.pbix`, which was saved from Power BI Desktop).
